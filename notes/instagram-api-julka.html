OutToday: połączenie Instagrama z botem – dla Julki

Ok. 20 minut, na komputerze, zalogowana na Facebooku, którym zarządzasz stroną OutToday.

Po co to jest: bot co rano przeczyta publiczne posty kont firmowych na Instagramie (hotele, beach cluby, galerie, centra handlowe, Louvre, Atlantis itd.) i wyciągnie z nich wydarzenia do apki: nazwę, datę, miejsce, cenę. Nic nie publikuje, nic nie lajkuje, nie czyta prywatnych kont ani wiadomości. Korzysta z oficjalnego API Mety, więc konto outtodayapp jest bezpieczne.

Krok 1. Sprawdź konto Instagram

W aplikacji Instagram na koncie outtodayapp: Ustawienia → Typ konta i narzędzia. Musi być konto firmowe (Business). Jeśli jest „osobiste” albo „twórca”, przełącz na Firma.

Potem na Facebooku, na stronie OutToday: Ustawienia → Połączone konta → Instagram → upewnij się, że jest połączone outtodayapp.

Krok 2. Konto dewelopera

Wejdź na developers.facebook.com → Get Started → przejdź rejestrację (potwierdzenie numerem telefonu, rola np. „Developer”).

Krok 3. Aplikacja

  1. My Apps → Create App.
  2. Nazwa: OutToday Bot, e-mail: outtodayapp.uae@gmail.com.
  3. Przypadek użycia: Other → typ: Business → portfolio biznesowe: pomiń (bez).
  4. Create app.

Krok 4. Token (krótki)

  1. Otwórz developers.facebook.com/tools/explorer.
  2. Po prawej: Meta App = OutToday Bot, User or Page = Get User Access Token.
  3. Permissions → dodaj: instagram_basic, pages_show_list, pages_read_engagement, business_management.
  4. Kliknij Generate Access Token → w okienku zaznacz stronę OutToday i konto outtodayapp → zatwierdź.

Krok 5. Token na stałe

  1. Obok tokenu kliknij niebieską ikonkę (i) → Open in Access Token Tool.
  2. Na dole kliknij Extend Access Token → skopiuj nowy, długi token.
  3. Wróć do Graph API Explorer, wklej ten długi token w pole Access Token.
  4. W polu zapytania (obok GET) wpisz me/accounts → Submit.
  5. W wyniku znajdź "name": "OutToday" i skopiuj wartość "access_token" tuż nad nią (bardzo długi ciąg znaków). To jest token strony – nie wygasa.

Krok 6. Przekazanie

Wyślij ten token strony Bartoszowi na WhatsAppie (nie mailem, nie publicznie). Bartosz wpisze go na GitHubie jako sekret IG_ACCESS_TOKEN i usunie wiadomość.

Nie podawaj nikomu hasła do Facebooka ani Instagrama. Token daje tylko odczyt i można go w każdej chwili unieważnić (zmiana hasła na Facebooku albo usunięcie aplikacji OutToday Bot).

Jeśli coś wygląda inaczej niż tu opisane, zrób zrzut ekranu i wyślij Bartoszowi.
