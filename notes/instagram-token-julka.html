OutToday: Instagram + bot (token) – for Julka

Part A on the phone (Instagram, English menus, ~3 min). Part B on a computer (Meta developers site does not work well on a phone, ~15 min).

Why: every morning the bot reads public posts of business accounts (hotels, beach clubs, venues, ticket sellers) and turns them into events in the app. It only reads – it never posts, likes or reads messages.

A. On the phone – Instagram app (@outtodayapp)

  1. Open your profile → tap ☰ (top right).
  2. Tap Account type and tools.
    • If you see Switch to professional account → tap it → choose Business.
    • If you see Switch account type, it is already professional – make sure it says Business (not Creator).
  3. Back on the profile tap Edit profile → under Public business information tap Page → Connect existing page → choose OutToday → Done. (If OutToday is already shown there, skip.)

B. On a computer – the token

Log in to Facebook (your account that manages the OutToday page), then:

  1. developers.facebook.com → Get Started → finish sign-up (confirm phone number, role: Developer).
  2. My Apps → Create App → name OutToday Bot, e-mail outtodayapp.uae@gmail.com → use case Other → type Business → skip business portfolio → Create app.
  3. Open developers.facebook.com/tools/explorer. On the right: Meta App = OutToday Bot, User or Page = Get User Access Token.
  4. Permissions → add: instagram_basic, pages_show_list, pages_read_engagement, business_management.
  5. Generate Access Token → in the pop-up tick page OutToday and Instagram outtodayapp → confirm.
  6. Next to the token click the blue (i) → Open in Access Token Tool → at the bottom Extend Access Token → copy the new long token.
  7. Back in Graph API Explorer paste this long token in Access Token. In the query box (next to GET) type me/accounts → Submit.
  8. In the result find "name": "OutToday" and copy the "access_token" value right above it (a very long string). This is the page token – it does not expire.

C. Send it

Send that page token to Bartosz on WhatsApp (not by e-mail, not in any group). He adds it on GitHub as IG_ACCESS_TOKEN and deletes the message.

Never send your Facebook or Instagram password to anyone. The token only allows reading and can be cancelled any time (change Facebook password or delete the OutToday Bot app).
If a screen looks different, take a screenshot and send it to Bartosz.
